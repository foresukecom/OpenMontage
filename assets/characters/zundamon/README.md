# ずんだもん立ち絵素材

このフォルダの素材は第三者の著作物のため、リポジトリには含めていない（`.gitignore` で除外）。
各自でダウンロードし、下記のファイル名で配置すること。

## 入手方法

- 素材: ずんだもん立ち絵素材 V3.2（製作: 坂本アヒル）
- 配布ページ: https://seiga.nicovideo.jp/seiga/im11206626
- 配布ページ記載のリンクから ZIP をダウンロードして解凍する（パスワードは配布ページを参照）

## 配置するファイル

| 配置名 | 元のファイル名 | 内容 |
|--------|----------------|------|
| `zundamon_v3.2_basic.psd` | `ずんだもん立ち絵素材V3.2_基本版.psd` | 正面向き・シンプルなレイヤー構造 |
| `zundamon_v3.2_upward.psd` | `ずんだもん立ち絵素材V3.2_上向き版.psd` | 上向き・シンプルなレイヤー構造 |
| `zundamon_v3.2_full.psd` | `ずんだもん立ち絵素材V3.2_全部詰め版.psd` | 頭の向き2種・細かいレイヤー |
| `readme_sakamoto_ahiru.txt` | `readme.txt` | 作者の readme（Shift_JIS） |

## 利用条件（要約）

- 動画等での利用、公式規約に準じた商用利用、改変・加工は可（作者 readme より）
- クレジット表記・ニコニコのコンテンツツリー登録は任意
- 公式ガイドラインにも従うこと: https://zunko.jp/guideline.html
  - 法人・業務での利用時は、ガイドラインの法人利用条件を確認すること
- VOICEVOX で生成した音声を使う場合は「VOICEVOX:ずんだもん」のクレジットが必須
